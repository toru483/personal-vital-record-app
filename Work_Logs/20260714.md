# 開発作業履歴

## [2026-07-14] 新規プロジェクト立ち上げおよびバイタル記録基本機能の実装

### 🛠️ 実施した作業
- **プロジェクトの初期化**
  - `rails new vital-check` コマンドによりアプリケーションの大枠を作成。
- **データベース構成の検討と決定**
  - 個人利用の利便性と安定性を考慮し、データベースを `PostgreSQL` から `SQLite3` へ切り替え。
  - `config/database.yml` および `Gemfile` の修正、`docker-compose.yml` 内の不要な `db` サービスコンテナ記述のコメントアウト（環境変数 `DATABASE_URL` の無効化を含む）。
- **コア機能の自動生成（Scaffold）**
  - カレントディレクトリ（`vital-check`）に移動後、バイタル記録を行うための主要なファイル群を一括生成。
  - マイグレーションを実行し、データベースにテーブルを適用。
- **動作確認**
  - `rails s -b 0.0.0.0` にてRailsサーバーを起動。
  - ブラウザで `http://localhost:3000/vital_records` にアクセスし、データの「表示」「保存」「削除」が正常に動作することを確認。
- **グラフ化の検証とリセット**
  - `Chartkick`（GemおよびCDN）による体重・血糖値・血圧のグラフ化を試行。
  - Rails 8におけるJavaScript（Turboなど）の読み込み干渉により「loading」表示のまま描画されない不具合が発生したため、コードを一旦リセット（次回以降に持ち越し）。

### 📋 生成されたデータ構造 (`VitalRecord` テーブル)

| カラム名 | データ型 | 説明 |
| :--- | :--- | :--- |
| `recorded_at` | datetime | 記録日時 |
| `weight` | decimal | 体重 |
| `blood_sugar` | integer | 血糖値 |
| `systolic_pressure` | integer | 最高血圧（上） |
| `diastolic_pressure` | integer | 最低血圧（下） |
| `memo` | text | メモ |
