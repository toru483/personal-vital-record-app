# Personal Vital Record App

個人の健康状態（体重・血糖値・血圧）を一画面で「素早く記録」「一覧で確認」「推移を分析」できる、1画面完結型の超快速バイタル管理システムです。

## 🚀 主な機能・特徴

1. **1画面完結型（3in1）エクセル風UI**
   - 画面移動を一切排除。上部フォームで打ち込み、中段テーブルで確認、最下部グラフで推移を瞬時に把握。
2. **快速クイック操作（2.5秒自動確定ポップアップ）**
   - 【登録】数値を打ってボタンを押すだけで、画面中央に「登録完了」がポップアップ表示され自動保存。
   - 【編集】一覧の「編集」を押すと、数値が上部フォームにシュッと自動逆転記。「変更を保存」で「変更完了」ポップアップが動作。
   - 【削除】「削除」ボタンからワンクリックで「削除完了」ポップアップが連動し、安全にデータを消去。
3. **過去10日分のバイタル平均値自動計算**
   - テーブル最下行に、直近10日間の「平均体重」「平均血糖値」「平均血圧」を自動で算出して表示。
4. **バイタル推移の折れ線グラフ（Chartkick）**
   - 体重、血糖値、最高/最低血圧の3つのグラフを最下部に常時描画。
5. **柔軟な日本時間（JST）カレンダー入力**
   - デフォルトで現在の日本時間が自動セット。過去の記録忘れもカレンダーから時計付きで手動入力可能。

## 🛠️ 開発環境の起動
本プロジェクトは開発効率を最優先した「開発環境専用コンテナ」を採用しています。エイリアスが設定されているため、以下の短いコマンドのみで起動します。

```bash
rails s -b 0.0.0.0
```
## 📋 記録項目
- 記録日時 (`recorded_at`)
- 体重 (`weight`)
- 血糖値 (`blood_sugar`)
- 最高血圧 / 最低血圧 (`systolic_pressure` / `diastolic_pressure`)
- メモ (`memo`)
